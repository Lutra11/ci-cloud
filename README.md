# 同频 · 课堂词云（Vue3 + Vite 纯前端版）

参考 `D:\CiCloud\class-cloud-package` 的界面风格，用 **Vue 3 + Vite + vue-router** 重写的课堂词云网页。**无后端、纯前端、无 localStorage**：数据只暂存在浏览器内存里，通过 `BroadcastChannel` 在同一浏览器的多个标签页之间**实时同步**（新打开的标签页会自动向已打开的标签页索取当前快照），刷新页面数据即清空。

## 路由

| 路由 | 用途 |
| --- | --- |
| `/cloud` | 大屏词云展示页（教师端）：开始 / 停止 / 清空、二维码、词云画布、提交记录 |
| `/input` | 学生输入页：姓名 + 关键词（可添加多个词） |

根路径 `/` 会自动跳转到 `/cloud`，其余未知路径也回到 `/cloud`。

## 交互逻辑

1. 大屏打开 `/cloud`，点击 **「开始收集词云」** 后，`/input` 才被允许输入（开始前打开输入页会显示“课堂尚未开始”）。
2. 学生扫 `/cloud` 左侧的**二维码**进入 `/input`，填写姓名，逐个输入词并点 **「添加」**（可加多个词，回车也可添加），再点 **「提交词云」**。
3. 提交的词实时出现在 `/cloud` 词云中：**所有词都会显示，出现次数越多的词字号越大**（基于第三方库 `wordcloud` / WordCloud2 按词频权重渲染）。
4. 点击 **「停止输入」** 后，`/input` 立即锁定，不再接受提交。
5. 点击 **「清空本轮词云」**（需连点两次确认）会清空本轮全部提交，并回到未开始状态，可重新开始。

## 运行

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，默认 http://localhost:5173
npm run build   # 打包到 dist/
npm run preview # 本地预览打包产物（支持 history 路由回退）
```

## 重要说明

- **数据是暂存的**：状态只存在内存中，**刷新页面即清空**（包括已收集的词和开始/停止状态）。如果所有标签页都关闭，数据随之消失，这是刻意为之的纯前端暂存方案。
- **同步范围**：`BroadcastChannel` 只能在**同一个浏览器**内跨标签页实时同步（例如大屏 `/cloud` 与另一标签页的 `/input`）。手机扫码打开 `/input` 属于另一台设备，无法同步到这台电脑的词云。
  - 若需要在课堂上真正实现“手机扫码 → 大屏实时出现”，必须接入一个后端（如参考版使用的 Supabase）做数据同步。
- **二维码**：二维码内容为「当前站点根路径 + `/input`」。开发时请用局域网地址（`vite.config.js` 已开启 `host: true`，启动后终端会打印 Network 地址）或部署后的公网域名打开 `/cloud`，否则手机扫 localhost 无效。
- **部署**：本工程使用 HTML5 History 路由（`/cloud`、`/input` 无 `#`），部署到静态托管时需要配置 SPA 回退（所有路径指向 `index.html`）。`vite preview` 已自带该回退。

## 技术栈

- Vue 3（`<script setup>` 组合式 API）
- Vite 6 + @vitejs/plugin-vue
- vue-router 4（History 模式）
- wordcloud（WordCloud2，canvas 词云渲染）
- qrcode（二维码生成）
